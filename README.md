# TechWise ICT — Year 4 MVP

A React/Vite MVP for the TechWise ICT Year 4 e-learning hub.

## Included

- Year 4 course with 3 topics and 11 lessons
- Textbook-guided objectives, terminology and examples
- Learn, Watch, Explore, Challenge, Quiz and Create lesson flow
- Interactive classification, matching and checklist activities
- Automatic quiz scoring and explanations
- XP and lesson badges
- LocalStorage learner progress
- Learner dashboard
- Basic teacher analytics view
- Parent/guardian read-only preview
- Final Digital Technology Challenge pathway
- Responsive/mobile-first UI

## Run locally

1. Install Node.js 18+.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local Vite URL.

## Build for Vercel

Run `npm run build`. The generated `dist` folder is the Vercel deployment output.

Vercel can also detect the Vite project automatically when the GitHub repository is imported.

## Notes

This is intentionally an MVP. Authentication, cloud database, teacher classes, real video hosting, project uploads, and persistent multi-device progress should be added in the next phase.

The Alice 3 activity is represented as a project checklist/submission record rather than attempting to execute Alice 3 inside the browser.
